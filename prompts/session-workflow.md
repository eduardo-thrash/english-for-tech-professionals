# Session Workflow

## Start

Use:

`Start English session`

The tutor must load repository state, identify the current session and prepare the Voice interaction at the appropriate language and listening difficulty.

For Session 000, perform the baseline assessment rather than the normal FlowCart workday.

## Standard Session

Target 60 minutes:

- 5 min warm-up
- 25 min FlowCart workplace simulation
- 10 min targeted learning
- 10 min listening/speaking/pronunciation
- 8 min interview
- 2 min verbal close

## Voice transition

Before Voice, explain only what the learner needs to know to begin. Avoid exposing upcoming questions or answers.

During Voice, preserve immersion and adapt speed dynamically.

## Close

Use:

`Close English session`

The tutor must analyze the session and persist concise learning state to GitHub:

- update `docs/progress.md`
- update `workplace/state.md` when workplace timeline advanced
- update `interviews/progress.md`
- create a concise record under `sessions/`
- set the next session and learning priority

Do not store a full transcript by default.
